## 一、系统的定义：有规律的变化形式

这边变化形式可以大可小，大到宇宙，小到原子，都可以是一个系统，前提是他是有规律的，即**变化在空间或时间中存在可预测的复现的情况**

**概念本身算不算系统呢？-> 不算，系统只针对感知到的世界，不包括思想本身**
```
感知分为两类，一种是外部世界的感知，一种是内部的心里变化，这两种是否可以视为同一种东西
- 抽象概念本身，意味着现实中不存在这样的东西，他是纯粹产生于意识的，他是我的理想化产物，那么这种东西应该怎么去分析呢
	- 抽象概念本身有自己的特性，但是绝对没有规律，他只是特性，并不需要去观察就能得出
```

本质上为小段有规律的分割，局限于一段形式，这段形式是什么
- 对外：功能性，即变化性，例如输入输出性
- 对内：组成性，即有更小的子系统组成

 


## 三、系统描述体系

怎么描述是最好的：
- 符合逻辑定律
- 奥卡姆剃刀
- 快速找到主要因素

我需要描述哪些东西：
- 系统本身的变化规律
- 系统之间的联系方式

我确立的描述到底是什么形式：
- 线性：优势是能直接说出来
- 结构性：优势是符合变化的天然描述结构

运用概念来描述

### 名词

系统本身作为一个类型可以用一个概念来表示：**系统/名词/对象**
- 符号描述：A、B、...表示多个系统
- 这个名词本身包含了这个系统中所有可能的变化，是一个变化集合，可能包含了系统的各种状态，类比向量空间
	- 名词本身作为一个变化集合，那么他是符合集合论的，所以名词与名词之间具有属于关系
	- 所以，A这个符号实际上表达的是 存在 A = {B,C,D,...}
	- 如果更加实例化这个名词
		- **形容词**：前面加修饰：例如「敌人的身体」首先，敌人有身体，但是「敌人的」并不是一般形容词，不过「敌人的身体」确实是「身体」的子变化类别

名词与命题的区别：名词没有真值

### 谓词
系统一旦定义好了，那么其可能所包含的状态、变化过程就都需要定义好，这个用**谓词函数**这个概念来表示可能的变化，一旦用上谓词，就相当于一个完整的描述了
根据变化设计的名词数量，分为一元和多元

#### 一元谓词
描述单系统的变化

| 系统可能的形式          | 符号表达                   |
| ---------------- | ---------------------- |
| 系统当前的状态          | S(A)                   |
| 系统的变化过程          | S1(A)->S2(A)   简化为V(A) |
| 系统状态的**量词/属性**描述 | S(A) = 180cm，T(A) = a  |
系统的属性描述是可以叠加的

#### 多元谓词
系统与系统间的交互带来的新的形式：系统间的关系，见概念之间的关系

同样二元谓词也是定义好的，表示系统之间可能的关系

符号表达为R(A,B)，这里的A，B可以是系统的任何形式

注意，这里只有逻辑关系，描述系统本身的变化，对于抽象描述之间的关系不属于谓词的范畴（例如属于关系）
