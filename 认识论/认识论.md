## 第一步：概念

### 概念
把一些变化中的**共性**提取出来，形成一个概念，用来「表示一定的变化范围」。这样当遇见一个新的变化时，能够根据其特征将其**归类到某一概念中**。
- 抽象是记忆能力的体现，没有记忆人就不会对想起其他的变化，进而进行归类

变化的共性：相同/重复的感知，包括性质、颜色、模式等一切感知到的东西，也可以是相似，本质是没有其他的东西能和比他再相似了

### 创造概念的方式分类
1. 具体概念：**在感知之流中，具有高度内部相关性的“重复模式”**。它不是一个“东西”，而是一个“稳定的变化集合”。将一个稳定的变化集合作为一个整体概念，例如苹果🍎、人、世界
	- 这种概念的内涵是模糊的，不确定的，所以具体概念没有本质，硬要说本质就是他的上层
	- 依赖感知与测量，永远带有误差和待发现属性
	- 直接对应感知
	- 顶层具体概念无法被严格定义，只能被“指认”或“预设”。 换句话说，具体概念的底层地基，不是逻辑，而是经验。
2. 抽象概念：把变化中的共性提取出来，理想化/简单化，例如数字，形状，颜色，时间，空间，存在，理性，光滑等，他来源于对现实的抽象，把部分完全可理解的东西单出抽出来
	- 间接对应感知
	- **认知自明公理（我思故我在）**：概念内涵是完全明确的，因为你就是它的运行实例：
		$\forall X\text{是世界的抽象} \left( \text{我是世界的一部分} \land \text{我认为我完全理解 \( X \) } \rightarrow  \text{我完全理解 \( X \) } \right)$
		- 这解释了我为什么能在构建认识理论框架之前就能理解世界
	- **内在不可定义公理（道可道非常道）**：顶层抽象概念完全无法定义，交给“大脑直觉”，停止追问（会陷入自指问题）
		$\exists X\text{是世界的抽象} \left( \text{我是世界的一部分} \land \text{我完全理解 \( X \) } \rightarrow \neg \text{我能定义 \( X \) } \right)$
	- 抽象概念可以解释具体概念：人天然有寻求“认知闭合”的需求（想把事情弄明白、找个确切的答案）。但“无限”违反了这种闭合。当大脑尝试将无限物体化（想象最大的数）却失败时，会产生一种强烈的情感体验——敬畏与崇高感。这种由于认知超载而产生的情绪，让我们误以为自己“把握”了无限。
3. 定义概念：对概念（包括上述两种概念）进行操作/定义产生新概念

### 概念的操作
将概念本身进行一定的操作（不是对概念对应的变化进行操作），产生新的概念

1. 定义/内涵/本质：将组合起来的概念，形成一个新的概念，这样能通过更短的概念描述更复杂的变化，方式对应本体论的三种实体：
	1. 对象定义/种属定义：C是A的B
	2. 命题定义：变化：存在a，b，a不等于b
		1. 大于关系，本身是一个命题，他描述了一个关系
	3. 谓词定义：a是b的后继，则a>b
2. 属性：将具体方式固定化，把概念的某个维度特意拿出来，用来特定化，即确定了更细致的变化
3. 分类/外延：将概念的子类展示出来，进行分类
	1. 概念的外延的有限/无限性：是否对应固定的变化（包括时空上的）
4. 拆分/构成：变化从整体到局部，从“背景”向“焦点”的逐级收窄。本质上是变化在各个维度的拆分（可以拆空间也可以拆时间）。例如：“大厅里（整体场景）有幅画。画里（过渡）有个穿红衣服的女人。她左手上（局部）戴着一枚戒指。”

### 概念间的关系
概念的操作让概念之间产生新的关系（相应操作具有对应关系）
1. 外延关系分类：
	1. 等价关系：两个概念描述的是同一个变化，外延完全相等
	2. 子/父类关系/属于/外延/种属：变化范围的扩大/缩小，概念的定义使得概念拥有了这个关系
	3. 交叉关系：具有全异关系的两个概念，一定属于同一个概念
	4. 全异关系（没关系也是一种关系）
2. 属性关系：例如大于小于，重要的，逻辑关系本质上是属性关系，因为描述了真值的属性
3. 构成关系：例如时间和空间的先后，系统的拆分
4. 交互关系：同一个构成概念之间的交互

### 概念的固有属性

所有概念都本身具有的属性，包括：
1. 真值：概念依据对应变化是否被实在感知，分为真、假以及即真又假，可以说是概念的固有属性
2. 周延性：来源于概念的分类，表示概念的外延是否有限，例如概念在时间上的无限性（永远）
3. 价值：对「我」的价值程度，不是说具体是什么价值，而是说价值本身是固有的

## 第二步：描述

通过概念描述世界

概念描述体系：明确概念的分类，以及概念的组织方式分类，包括：

1. 句法：完整描述/句子的分类
2. 词法：组成句子的概念的分类
3. 组织形式：概念组成句子的方式

### 组织形式
概念因为交互可以抽象成一个多维向量空间中的一条向量，具体有两种形式：
- 一元限定：例如名词、形容词、状语
- 多元限定：例如动词、介词、连词
	- 限定需要一定的规则，具体体现为，限定左右两边的类型

### 句法
句子：一段完整描述

句子的完整形式（这是定义）：
- 性质命题：一个概念的变化，具体解释为一个概念具有什么性质（变化空间的缩小），或者一个概念在当前时空下的状态
- 关系命题：两个概念的变化，可以解释为关系

句子的特性：
- 句子本身可以作为概念进行嵌套
- 依照概念是否未知，可以分为疑问句和陈述句两种类型

### 词法
词素：句子的组成部分，分为三部分：
- 不能缺失的两个部分：名词和谓词
- 用来扩展的部分：修饰词
- 用来连接变化进行扩展的部分：连词

词素分类：
- 名词：系统本身，变化的集合
- 谓词：确定系统的当下变化，同样是变化的集合
	- 一元谓词：性质
	- 多元谓词：关系
	- 介词短语可以组成谓词，这个是语法的部分
- 连词：连接变化的词语
	- 属性连接
		- 逻辑关系
		- 价值连接，例如强调
	- 构成连接，例如时空的先后关系
- 修饰词：可添加在任意类型词语后面，进而具体化

	- 谓词修饰语

	- 状语，用来独立修饰当前变化状态，定型的是时空状语

		- 否定词
		- 对名词的全称/特征限制

## 第三步：推理

在概念描述体系框架基础上，研究真值的联系
- 周延会影响真值

### 命题

#### 命题的定义
满足逻辑四定律的句子（这个有点嵌套定义了，后面改一下）
1. 同一律：A 是 A 
	-  A → A  
2. 矛盾律：A 不是 非A 
	-  ¬（A ∧ ¬A） 
3. 排中律：A 或 非A 
	-  A ∨ ¬A
4. 充足理由律：A 真，因为B为真且B能推出A
	-  (B ∧ B -> A) -> A

所以疑问句不是命题

#### 命题的分类
这里全部是二分类，也就是说，一个命题需同时具有下面的分类项：
- 关系命题/性质命题：从句子中继承下来
- 特称命题/全称命题：不存在周延名词/存在周延名词
- 概率命题/非概率命题：或然表示0%-100%，必然表示100%，不可能表示0%
- 复合命题，多个命题的真值计算组合形式

![命题](哲学/认识论/assets/命题|500)

### 推理
#### 推理的定义
通过已知命题的真值来推导出新的命题的真值，本质上是建立真实属性关系A->B

#### 推理的分类
1. 必然性推理/事实性推理/演绎推理：全称->全称、全程->特称
	1. 谓词逻辑推理：通过概念之间的关系完成推理
		1. 一元谓词逻辑，即传统三段论
		2. 多元谓词逻辑，即关系推理，需要定义好关系的推理规则，例如：
			- 对称性：ARB $\leftrightarrow$ BRA
			- 传递性：ARB $\land$ BRC -> ARC
			- 自反性：ARA = 1
			- 还有连通性、欧几里得性、串行性等其他关系
	2. 复合命题推理：通过部分真值计算整体组合的真值
	3. 概率推理：复合命题的基础上增加概率
2. 或然性推理：推导出的结论不是100%为真
	1. 全称命题推理：特称->全称、全称->全称、特称->特称（有意义吗）
		1. 归纳推理：经验角度，举出概念的有限外延， 然后判断他们是事实，进而推出概念本身为真，形成规律
		2. 类比推理：A有某总规律，A和B类似，那么B有可能有某种规律
		3. 假设检验：先想象出一个规律，然后通过该规律推理出预估的现象，最后进行验证
			1.  需要有验证方式，这样才能让假设的规律变得有意义，例如缸中之脑如果没有检验方式就没有意义
			2. 假设既可以是新规律，又可以是已有规律的子集
	2. 溯因推理：已知B为真，找到一个A，是A->B为真
		1. A可以是多个命题
		2. 如何保证溯因推理的可靠性：例如我今天心情不好是因为太阳从东边升起
		3. 如何处理原因有很多的情况：列举互相矛盾的可能性，然后一一排除

![推理](哲学/认识论/assets/推理|600)

#### 推理逻辑

一些问题：

	- 所以不是知道推理过程就完了，因为还有类似排除法这样有用的推理形式，是上述推理分类中的子集
	- 高效推理：什么推理是高效的（注意不是有效的），排除法显然是一种高效推理，真的吗？

## 第四步：知识

定义：为真的全称命题

### 知识的分类
- 先验知识：针对抽象概念，必然真理，100%为真的命题
	- 原材料：定义+公理（不推导，直接预设），公理更像是一种假设，例如两点之间直线最短，经济学理性人
	- 制成品：定理
- 后验知识：针对具体概念，或然真理，主体从经验角度观察而来，不可能永远为真，不可能100%是真，例如黑天鹅事件，不过我们可以改口：我们迄今为止见到的天鹅都是白色的，但这是事实，不是规律
	- 原材料：定义+观察归纳
	- 制成品：定律/规律
- 混合知识/理论：先验+后验是可以组合起来的，只要在规律的基础上加上假设就能够进行组合，就能形成新的知识
	- 先验可以单独拆开去分析，但是后验一定要用先验去分析，我只能用我理解的东西去解释模糊的东西
	- 组合的具体形式
		- 规律可以视为一种假设，具有一定的置信度
		- 可以在规律的基础上进行假设新的东西，进而得到新的规律

### 知识体系

**以定义为基本符号单元，以公理为逻辑起点，经由演绎与归纳两种推理路径，将所有为真的全称命题（包括先验定理与后验规律）按照研究对象的内在层级组织起来的、具有严密逻辑结构的命题集合。**

可以分为先验知识体系，和后验知识体系（**解释具体概念的框架**）

先验体系就是用来解释后验的，但是先验可以自成体系，而后验只能用先验来表示

构建知识体系遵从如下原则：
1. **奥卡姆剃刀定律**：在能接近本质的情况下，越简单描述越好
2. **自顶向下分类原则**：父知识包含顶层性质，他的子类会继承父知识，并添加一些新的东西
3. **围绕一个主题/对象**：知识都有一个主题，这个主题就是名词，围绕这个主题设定一系列的知识，然后依据自顶向下原则，设定名词的外延的一系列知识，需要回答下面的问题
	1. 它属于那个概念
	2. 在父类的概念上多了些什么，分别从性质、关系入手展开陈述

所以，在构建知识体系时，应该遵循这样的过程：
1. 定义一个概念对象，即变化集合
2. 基于概念的命题，包括规律命题、假设命题（关系命题和性质命题）
3. 在这些命题的基础上，推导出新的命题
4. 在新命题的基础上继续加假设+新规律，继续推导出新的命题
	1. 但是假设的东西太多了，如何只保留有用的假设呢，例如我不需要假设和我无关的东西
	2. 有效假设：贴近规律，例如理性人假设就是贴近规律的
	3. 事实，需要事实进行检验，用来保证命题的可靠性
