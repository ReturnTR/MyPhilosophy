
如何从把混乱的体系思路逐渐变得清晰

## 目的清晰

目标：构建完整的体系
什么是体系呢，你知道吗：
- 理清所有概念之间的联系
- 不需要的概念去掉
- 需要新增的概念加上

不断的想出问题并解决问题

实现细节扩展：
- 联系是什么样的，有什么类型

## 路径清晰

1. 将已知的概念联系铺开
2. 将不知道放入哪里的概念放在一边
3. 思考新概念放在哪里，结论上有一下几种情况
	1. 在新的概念下延伸
	2. 修改已有联系进行修正




```
例如
假设针对的问题是对概念的未知，那么我应该怎么做？
1. 找概念子类：外延
2. 找概念父类：种属
3. 找边界条件
4. 找区别，独特性：限制词，可以通过子类来找
5. 概念 = 独特性限制词+种属，A的B，可以加上例如C，D
怎么找：联想回忆

可能的风险/障碍
- 联想，回忆不到
	- 解决方案：外部工具搜索，例如搜索引擎、AI
- 种属也不清楚
	- 解决方案：继续搜种属
- 定义不能表达他的内涵，例如dsh是deepseek公司做的agent框架，但是dsh的内部细节是不清楚的
	- 内部细节是概念的性质，不在定义范畴中
	- 思考到底是哪个父类能这么做

进化方向，如何做的更好：
- 大脑的概念变多，这样比较好联系
- 扩展概念定义结构

```
